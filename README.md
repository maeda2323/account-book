# 人事管理ダッシュボード

会社の人事情報CSVをアップロードすると、管理画面から以下を確認できます。

- 年代別社員数（20代/30代/40代/50代/60代）
- 勤続年数（平均・分布）
- 部署別社員数
- 男女別社員数
- 入社人数（年次・累計）
- 退職人数（年次・累計）

## 管理画面メニュー

- データアップロード
- ダッシュボード

CSVを読み込むと自動でダッシュボード画面に切り替わります。

## ローカルサーバーで起動

```bash
python -m http.server 4173
```

ブラウザで以下にアクセス:

- `http://127.0.0.1:4173/index.html`

## 推奨CSV列

- 社員ID
- 年齢
- 部署
- 性別
- 入社日
- 退職日
- 勤続年数

> 列名は日本語・英語両方に対応しています（例: `年齢` / `age`, `部署` / `department`）。
